# Paper → code map

All commands run from the repository root with `PYTHONPATH=.` and the
`tcrpmhc-vicreg` environment active. Anything marked (no GPU) reads committed
CSVs or saved latents instead of retraining.

## Data

| Paper item | Command / file |
|---|---|
| Split counts 24,456 / 1,672 + 1,670 / 1,900 + 1,900 | `data/processed/SPLIT_COUNTS.json`, checked with `sha256sum -c data/processed/CHECKSUMS.sha256` (no GPU) |
| Whole construction chain | `python src/data/prepare_data.py --hla-fasta data/raw/hla_prot.fasta` |
| Seed-42 split and novelty-regime construction | `python src/data/split_positives.py --seed 42` |
| Occurrence-matched decoy generation | `python src/data/build_eval_decoys.py` |
| MHC sequences from IPD-IMGT/HLA 3.60.0 | `python src/data/add_hla_sequence.py --hla-fasta data/raw/hla_prot.fasta` |
| Novelty-regime row counts (3,290 / 264 / 240) | `src/data/novelty_regimes.py::label_split` on the frozen test split (no GPU) |

## Table 1 — main five-seed results

Internal-test and IMMREP metrics for the three input families with and without
VICReg, mean ± SD over seeds 31/37/43/49/55.

```bash
PYTHONPATH=. python experiments/run_five_seed.py          # 15 training runs
PYTHONPATH=. python scripts/make_table1.py                # renders from results/ (no GPU)
```

Outputs: `results/main_results.csv`. The novelty-regime rows come from
`results/novelty_regimes.csv`, regenerated by
`PYTHONPATH=. python experiments/novelty_regimes.py` (no GPU).

## Hyperparameter sweep (appendix)

Single seed (31), α = β ∈ {1, 25, 50} × d ∈ {64, 128, 256}, δ = 1. Selection used
validation peptide-weighted AUROC only; the test and IMMREP columns are
diagnostic.

```bash
PYTHONPATH=. python experiments/hyperparameter_sweep.py
```

Output: `results/hyperparameter_sweep.csv`, all 27 rows unreduced.

## Table 4 — constrained pairing-shuffle control

Jointly reassigns pMHC units across the 24,456 training TCR rows, preserving the
pMHC multiset and forbidding recorded training-positive triples, with one
independent reassignment per seed. Validation, test and IMMREP stay unshuffled.

```bash
PYTHONPATH=. python experiments/constrained_shuffle.py
```

Output: `results/shuffle_control.csv`, which keeps `best_epoch` so the epoch-1
selection in all five shuffled runs can be checked.

TCR norm, dot product, cosine and full negative-MSE scoring. Gives TCR-norm
AUROC 0.500 on the occurrence-matched test set.

```bash
PYTHONPATH=. python experiments/score_decomposition.py   # uses saved latents (no GPU)
```

Output: `results/score_decomposition.csv`.

## Stagewise transfer diagnostic

Extracts the fixed input, pre-expander and final latent representations, then
computes pairwise MSE, cosine distance, norm ratio, covariance-trace ratio and
Cliff's δ between internal test and IMMREP.

```bash
PYTHONPATH=. python experiments/stagewise_transfer.py     # loads validation-selected checkpoints
```

Outputs: `results/stagewise_transfer.csv` and `figures/stagewise_diagnostic.png`.

## Figure 2 — geometry multipanel

Panels (b) and (c) group TCRs by peptide sequence irrespective of MHC. Panel (d)
ranks explicit peptide–MHC complexes.

```bash
# 2b same-peptide recovery
PYTHONPATH=. python experiments/same_peptide_recovery.py --split test

# 2c k-nearest-neighbour same-peptide enrichment, k in {5, 10, 20}
PYTHONPATH=. python experiments/neighbour_enrichment.py

# 2d multi-cognate retrieval (Recall@10)
PYTHONPATH=. python experiments/multicognate_retrieval.py --split test

# assemble the four panels (no GPU)
PYTHONPATH=. python figures/make_figure2.py --split test
```

The design constants appear in the output tables:

| Quantity | Value |
|---|---|
| Panel (b) same-peptide pairs | 35 peptides × 10 pairs = 350 |
| Panel (b) matched different-peptide pairs | 350 |
| Panel (c) neighbourhood sizes | k ∈ {5, 10, 20} |
| Panel (c) query set | full positive internal test; k-NN after identical-TCR exclusion |
| Panel (c) eligible peptides | 35 peptides with ≥ 5 distinct TCRs (1,498 queries; same eligibility as 2b) |
| Panel (d) queries | 77 multi-cognate TCRs |
| Panel (d) gallery | 345 unique peptide–MHC complexes |
| Panel (d) random Recall@10 | 10 / 345 = 2.9% |

Outputs: `results/geometry_retrieval.csv` (Figure 2 compact summary), with the
per-seed, per-TCR and evaluation-pair tables under
`results/paper_analysis/refined_geometry/` and
`results/paper_analysis/crossreactivity/knn_peptide_purity.csv`. Figure:
`figures/test_geometry_multipanel.png`. The earlier frequency-capped same-peptide
table is under `results/legacy/`.

## Metric definitions

All metrics are defined in `src/evaluate.py`: global AUROC, peptide-weighted
AUROC, peptide-macro AUROC and McClish standardised partial AUROC at FPR 0.1.
`src/models/scoring.py` defines the score `s(T, P) = -(1/d)·||z_T − z_P||²` and
its decomposition variants.

Extra diagnostics that are not part of the submitted figures (frequency-capped
same-peptide protocol, CKA/Procrustes, t-SNE, pMHC permutation) live under
`experiments/legacy/`.
